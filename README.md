# Digitally Correct 2.0: VIP Cinema Screening Room (`reel.digitallycorrect.co.za`)

Official web screening room for **The Mint Spark Odyssey** (`60fps` programmatic showreel), built for Digitally Correct (`en-ZA`, `ZAR`).

## Media Staging

Run `npm run stage-media` to stage web-optimised (`-movflags +faststart`, under `35 MB`) streams and Open Graph imagery (`showreel-poster.jpg` and `og-preview.jpg` at `1200x630`) from `~/Projects/digitally-correct-showreel` without altering `exports/`.
